# RHDG-DSNMF

MATLAB implementation of RHDG-DSNMF for multi-view clustering.

Add `code` to the MATLAB path and run `run_demo` for one experiment or
`run_all_experiments` for the complete six-dataset protocol. Dataset files are
not included. Place the benchmark `.mat` files in a local `data` directory; the
accepted filenames and variables are handled by `load_mv_dataset.m`.

The implementation was tested with MATLAB R2019b.
